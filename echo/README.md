# Echo example

> Example status: **Legacy**
>
> This example places a Realtime SFU bearer token in browser code. Use it only
> to inspect the low-level API flow. Do not deploy it or use its credential
> pattern in an application.

To run this local example, update `APP_ID` and `APP_TOKEN` after creating a
Realtime SFU application in the [Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/realtime/sfu).
